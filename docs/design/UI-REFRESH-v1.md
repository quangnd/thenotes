### Checks that worked, and limits

- Desktop search opens with one click; query `ghi chú` produces results ([capture](evidence/ui-00-2026-11-07/search-desktop-light.jpg)); Escape dismisses the search overlay. Search result activation, empty/error states and dark search overlay were not exhaustively tested.
- Desktop Explorer expands to a flat list ([capture](evidence/ui-00-2026-11-07/explorer-desktop-light.jpg)); mobile Explorer opens/closes as a full-screen list. Title/home link is visible. Browser automation clicks around viewport transitions required fresh state checks; uncertain intermediate actions are not treated as product defects.
- Activating the MOC's first article link reaches [the evergreen-writing note](evidence/ui-00-2026-11-07/internal-link-desktop-dark.jpg). Readwise backlink `Kawara` reaches [Kawara](evidence/ui-00-2026-11-07/backlink-destination-desktop-light.jpg). These are sampled navigation successes, not an all-links audit or proof of SPA lifecycle correctness.
- Light/dark controls changed the actual `saved-theme` state; the four-page matrix contains both themes. Graph nodes render on MOC in both themes; Global Graph opens with nodes in light mode. Node selection, zoom/drag and dark global graph were not tested.
- `scrollWidth` equals viewport width in every saved capture, including 375px home/image states. No page-level horizontal overflow was measured in these sampled states. Full-article scrolling, all embeds, 200% zoom and all breakpoints remain regression tests.
- Readwise GIFs load at 1451px/1504px natural widths and approximately 742px desktop, 342px mobile, 327px small-mobile display widths. Aspect ratios are retained in the inspected images. Hidden/offscreen images may have zero layout width in the manifest; that alone is not a loading failure.
- Hover previews are enabled in source but were not interactively verified: the available documented browser controls did not expose a hover action. No screenshot is offered as proof of hover behavior. Screen-reader flow, keyboard focus trapping, native touch keyboard, reduced motion and cross-browser behavior remain unverified.

## 3. Source facts, separately from live findings

At the pinned `v5` source:

- [quartz.config.yaml](../../quartz.config.yaml): search, graph and backlinks have `display: desktop-only`; SPA and popovers are enabled. The table-of-contents plugin is enabled without a layout placement. This explains a configuration gap to inspect during UI-03, not a complete root-cause diagnosis. Recent-notes is disabled.
- [custom.scss](../../quartz/styles/custom.scss) imports [typewriter.scss](../../quartz/styles/themes/typewriter.scss). Theme variables override the YAML fallback palette. Preserve that cascade until an implementation PR verifies it.
- [content/index.md](../../content/index.md) contains the welcome, attribution and four existing topic links. Discovery can build on these without moving or renaming the flat vault.
- Live computed Readwise paragraph typography was 16px / 24px, with `iA Writer Mono V`, `iA Writer Quattro S`, then monospace fallbacks; reader width was 742px at 1440px. Computed font family does not prove which font supplied every Vietnamese glyph.
- Workflow audit: `deploy-pages.yaml` deploys on pushes to `v5` or manual dispatch. CI and preview workflow jobs are guarded by `github.repository == 'jackyzha0/quartz'`, so their presence does **not** imply this fork receives working checks/previews. This PR changes no workflows and triggers no deployment intentionally. Do not merge it without owner review.

## 4. Intended layouts — proposals for review

Keep Quartz 5, current parchment/charcoal/purple palette, typewriter body, wikilinks, backlinks, hover previews, dark mode, graph and existing note URLs. These schematic wireframes describe future structure; they are **not screenshots or implemented mockups**.

```text
DESKTOP HOME (1440px)
┌ Discovery ~240px ┐  ┌ Reader ~680–760px ──────────┐  ┌ Context ~220px ┐
│ Site title       │  │ Short welcome + attribution │  │ Quiet optional │
│ Search / theme   │  │ Start here                   │  │ graph entry    │
│ Four topic links │  │ [Topic 1]       [Topic 2]     │  │ (no hero graph)│
│ All notes toggle │  │ [Topic 3]       [Topic 4]     │  └────────────────┘
└──────────────────┘  │ Selected notes → 3–5 links   │
                      │ Recently updated → 5 links  │
                      │ About / existing long intro │
                      └─────────────────────────────┘

DESKTOP ARTICLE (same grid)
┌ Discovery ───────┐  ┌ Reading ────────────────────┐  ┌ Context ───────┐
│ Search, topics, │  │ Title, modified / read time  │  │ On this page   │
│ all notes       │  │ Body + wikilinks             │  │ heading links  │
│                 │  │ Responsive image             │  │ Backlinks      │
└─────────────────┘  │ Authored caption (if present)│  │ Graph (toggle) │
                     └─────────────────────────────┘  └────────────────┘

MOBILE HOME (390px / 375px)       MOBILE ARTICLE
┌ ☰  The note       ⌕  ◐ ┐     ┌ ☰  The note       ⌕  ◐ ┐
│ Short welcome           │     │ Title + metadata         │
│ Start here              │     │ On this page ▸ (if long) │
│ [Topic 1]               │     │ Body, links              │
│ [Topic 2]               │     │ Image (fits width)       │
│ [Topic 3]               │     │ Caption if authored      │
│ [Topic 4]               │     │ Backlinks ▸              │
│ Selected / recent       │     │ Graph entry (optional)   │
└─────────────────────────┘     └──────────────────────────┘
```

Use existing responsive layout machinery. Proposed sizing: 24–32px desktop gutters, 20–24px mobile gutters; stack the right rail below the article when three columns cannot fit without narrowing the reader. Preserve the existing approximately 800px mobile boundary initially; inspect 799/800/801px and tablet widths before settling exact transition rules.

Homepage: elevate these four current destinations, with owner-reviewed Vietnamese one-sentence descriptions: `Ghi chú thường xanh`, `MOC Hệ thống viết ghi chú`, `MOC Coi trọng công việc tri thức`, `MOC Những gì đang chiếm tâm trí tôi - Andy`. Two columns on wide readers; one column at 390/375px. Each card has one clear link and visible focus. Keep existing author text/translation accessible; any shortening/reordering needs owner copy approval. Selected notes are explicit owner curation, not inferred popularity. Recent notes use existing modified metadata, newest first with stable title tie-break, exclude unpublished/unlisted pages, and avoid fabricated dates. Prefer the existing RecentNotes component after evaluating its configuration; no new index service or vault migration.

Article: render TOC only for eligible heading-rich notes (proposal: at least three headings). Prefer the existing plugin/component; retain heading IDs and deep links. TOC precedes backlinks and graph in the desktop context rail. On narrow layouts place a collapsed, labelled TOC before prose, without duplicating tab stops. A short note has no empty TOC. Do not rewrite source heading levels automatically; the Chapman note mixes H2/H3/H4, which requires a separate editorial decision if changed.

### Type, spacing and images

| Element          | Proposed starting point for UI-03 comparison                                                                                                                                                                                                                                    |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Body             | Keep current font stack and 16px size initially; compare 1.5 with 1.6–1.65 line height using real Vietnamese paragraphs. Choose after side-by-side review, not a new theme.                                                                                                     |
| Reading measure  | Retain roughly 680–760px desktop reader; target about 65–80 monospace characters per line where practical. Mobile uses available width after gutters.                                                                                                                           |
| Title / headings | Title 28–32px desktop, 24–28px mobile; H2 around 24px, H3 20–22px; allow long Vietnamese headings to wrap naturally. Preserve semantic hierarchy.                                                                                                                               |
| Rhythm           | 8px spacing unit; paragraphs 16–20px apart; section headings about 32px above / 12–16px below; cards 16–20px padding and 12–16px gaps.                                                                                                                                          |
| Supporting text  | Metadata/captions 14px with 1.5 line height; quieter than prose but readable in both themes. Verify contrast, focus and link states; no contrast certification in this baseline.                                                                                                |
| Images           | Max width 100%, auto height, no cropping or forced enlargement of small originals. Preserve GIF animation and native aspect ratio. Provide an accessible original-resolution link where image text needs inspection; don't invent a lightbox before checking existing behavior. |
| Captions         | Place authored captions immediately below images, aligned to reader width. Do not turn filenames/alt text into captions automatically. Keep attribution and alternative text distinct.                                                                                          |

### Mobile navigation/search states

| State                     | Proposed behavior / exit                                                                                                                                                                                                                                                         |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Reading                   | Sticky compact header with menu, home title, search and theme. Search opens directly in **one tap**, with no menu prerequisite. All four controls fit 375px; aim for 44px touch targets and accessible names.                                                                    |
| Menu open                 | Navigation sheet with curated topics first and all-notes explorer second; current location indicated. Close control is always visible. Trap modal focus, prevent background scrolling, Escape/backdrop close, restore focus and prior reader scroll. Opening search closes menu. |
| Search open / empty query | Labelled dialog with query field and close control. Focus input on open; keep both query and close reachable with the software keyboard. Empty query shows guidance, not an error.                                                                                               |
| Results                   | Reuse existing search; keyboard arrows/Enter and touch activate notes, loading state is explicit, result labels wrap, highlighted text stays readable in both themes. Navigation closes overlay and moves focus to the new article.                                              |
| No results / load failure | Say which query had no results and allow edits/clear. If the index fails, explain and offer retry; do not leave a blank modal.                                                                                                                                                   |
| Dismiss / route / theme   | Escape and close restore trigger focus; browser Back must not strand an overlay. Theme choice survives navigation. No duplicate listeners after repeated SPA transitions.                                                                                                        |

## 5. Inspiration, not copying

The [Quartz showcase](https://quartz.jzhao.xyz/showcase) links Jacky's Garden and The Pond. The [Garden homepage](https://jzhao.xyz/) exposes selected writing, recent notes and introductory entry links: adopt that distinction between curation and recency, using The Notes' existing MOCs. [Obsidian Publish](https://help.obsidian.md/publish) is a useful model for publishing a linked knowledge base with pragmatic discovery; use that intent without importing its platform or folder structure. The Pond remains the reading/typography reference approved in #10; its homepage did not yield readable content through text retrieval here, so no new visual comparison is claimed. Reference pages were consulted as text, not viewport-matched screenshot studies. No reference palette, branding or custom animation is prescribed.
