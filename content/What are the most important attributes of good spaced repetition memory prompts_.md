Ghi chú này tổng hợp các ý tưởng về cách mã hóa kiến thức vào thẻ của [[Spaced repetition memory system|hệ thống ghi nhớ lặp lại ngắt quãng]], cả để hỗ trợ ghi nhớ sự kiện lẫn thúc đẩy sự hiểu biết phong phú hơn ([[Spaced repetition memory systems can be used to develop conceptual understanding|Dùng hệ thống ghi nhớ lặp lại ngắt quãng để hiểu khái niệm sâu hơn]]).

Đang trong quá trình xây dựng:

- [[Spaced repetition memory prompts should be concise|Thẻ ghi nhớ lặp lại ngắt quãng nên súc tích]]
- [[Spaced repetition memory prompts should usually focus on one idea|Thẻ ghi nhớ lặp lại ngắt quãng thường nên tập trung vào một ý tưởng]]
- [[Spaced repetition memory prompts should encode ideas from multiple angles|Thẻ ghi nhớ lặp lại ngắt quãng nên mã hóa ý tưởng từ nhiều góc độ]]
    - [[Spaced repetition memory prompts should connect and relate ideas|Thẻ ghi nhớ lặp lại ngắt quãng nên kết nối và liên hệ các ý tưởng]]
- [[Avoid orphan spaced repetition memory prompts|Tránh thẻ ghi nhớ lặp lại ngắt quãng mồ côi]]
- [[Spaced repetition memory prompts should ensure reviewers must retrieve answers from memory|Thẻ ghi nhớ lặp lại ngắt quãng nên đảm bảo người ôn tập phải truy xuất câu trả lời từ bộ nhớ]]
    - [[Avoid yes-no spaced repetition memory prompts|Tránh thẻ ghi nhớ lặp lại ngắt quãng dạng có-không]]
- [[Spaced repetition memory prompts should be written to discourage shallow “pattern matching”|Thẻ ghi nhớ lặp lại ngắt quãng nên được viết để không khuyến khích "nhận dạng mẫu" nông cạn]]
